
Iglesia Cristiana Aleluya — Sitio SPA (Single Page)

Estructura
----------
- index.html
- assets/css/style.css
- assets/js/app.js
- images/logo.*     ← reemplaza por tu logo (mismo nombre)
- images/fondo.*    ← reemplaza por tu imagen de fondo (mismo nombre)

Cómo subir
----------
1) Sube toda la carpeta al hosting (cPanel / Netlify / Vercel / GitHub Pages).
2) Mantén la estructura de carpetas.

Cambiar imágenes
----------------
- Reemplaza "images/logo.png" (o .jpg) por tu paloma.
- Reemplaza "images/fondo.jpg" por tu imagen de fondo.
- Puedes agregar más imágenes a la carpeta "images/".
